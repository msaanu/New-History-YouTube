# Asia’s Past — handover for a new local project

## Read this first
This is a portable production brief, not a verbatim archive of all prompts or research from the previous chat. A new chat must not claim access to that chat, its sources, or its files unless they have been provided. The GitHub video-delivery branch contains video downloads and this guide, not the complete editable HyperFrames project or asset library.

## Channel and editorial requirements
Channel: Asia’s Past. Research-led immersive history across Korea, Japan and eventually other Asian countries; not limited to royalty. Use second-person narration (you), curiosity hooks, human stakes, and clear explanations. Target substantive episodes of at least 20 minutes; the first completed episode runs 19:35. Do not pad. End with a supported connection to the present where relevant, then a thoughtful audience question and an invitation to comment.
Every historical assertion must have a checked, traceable source. Maintain a claim-to-source ledger with page/section references and accessible links. Distinguish evidence, scholarly interpretation and illustrative reconstruction. No invented dialogue, thoughts, quotations, statistics or records presented as fact. Do not transfer one historical person’s documented feelings to another. Cite sources in the description. Research before narration recording. Use canonical names on screen, even where the TTS input uses phonetic spelling.

## Approved visual direction
Rich, clear colored historical surroundings and simplified expressive round-faced human characters. Correct country, period, rank, clothing, insignia, architecture and props. Do not copy Ottoman Days characters, images or scripts. Adapt its explanatory visual grammar.
1920×1080, 16:9. Full scenes, no accidental cropping or enlarged contact-sheet panels. Hard cuts. No fades, wipes, zooms or pans. Voice only: no music or effects unless the user changes this preference.
Palette: jade #245B50; ivory #F5EBDD; ink #202B33; terracotta #B6533D; antique gold #C6A15B. Natural wood and blue-gray tiles as historically appropriate.
Fonts from the completed project: Bitter for contextual statements, Atkinson Hyperlegible for supporting lines and dates, Barlow Condensed ExtraBold for brief emphasis.
Text belongs on plain ivory cards, not walls of subtitles. Use short meaningful clauses when a bare repeated name is confusing. Display key names, dates and processes only when narration introduces them.
Joseon warning: red alone does not mean royal. Garment type, insignia, rank, occasion and period determine accuracy; distinguish royal dragon insignia from officials’ rank badges. Modern research scenes must be clearly identified as present day. A generic modern reader is not an authenticated portrait of a named scholar.

## New visual improvement
Reference: https://youtu.be/u1WricNukpA
The uploaded reference was sampled visually across its duration, not exhaustively audio-transcribed. Samples show rich scene illustrations alternating with isolated objects, single characters on plain backgrounds, short text cards and comparison/group diagrams.
Apply noun/action-level visual coverage. If narration names salt, show a period-appropriate depiction of salt. When it describes an action, show that action. Use isolated object inserts, character reactions, setting shots, process diagrams, comparisons and brief contextual cards as the narration requires. Do not default to generic palace scenes or repeat illustrations to fill time. Do not force cuts every 1–2 seconds: hold a relevant image as long as needed to understand it.
Prepare a visual coverage table: audio start/end, exact spoken clause, intended meaning, asset, framing, on-screen words, historical verification, reason for shot change. Every clause must be accounted for. Time important object inserts to the corresponding spoken words. Represent abstract ideas with clearly explanatory diagrams; do not fabricate historical evidence to illustrate them.

## Workflow and cost control
1. Verify this session actually has authorized access to the local project folder; ordinary ChatGPT chat does not automatically gain laptop access.
2. Inspect hardware, disk space and existing tools before installing anything. Check Node (use supported LTS; prior project used Node 24), HyperFrames, FFmpeg/FFprobe, browser and fonts. Ask before admin/password steps. Use installed HyperFrames skills and its doctor checks.
3. Agree on title and research brief; source ledger; fact-checked script; pronunciation guide; user narration.
4. Align supplied audio in its numbered order. Map clauses to visual beats before generating art.
5. Approve a representative sample including full scene, object insert, action, diagram and plain text card.
6. Reuse approved assets. Generate only missing visuals. Keep a manifest so completed assets are never regenerated accidentally.
7. Build and validate the HyperFrames composition; review at native resolution. Save an editable project containing HTML, assets, audio, fonts, timings and source notes.
8. Show a preview using an actually available preview surface. Do not promise a side-panel editor merely because a plugin is installed. Do not export MP4 until this project’s user approval is explicit.
9. Save approved original MP4 directly into the local project’s exports folder. Make smaller copies separately; never replace the original. Verify duration, resolution, narration order, visual sync, first and final shots.
10. Preserve a portable project checkpoint after each stage. Use local compute for editing/encoding when available; do not promise zero credit usage for chat or generation services.
