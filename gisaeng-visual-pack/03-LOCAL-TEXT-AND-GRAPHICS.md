# Local graphic and text-card instructions

These C-ID frames are built in local HyperFrames. They require NO image generation. 1920×1080. Warm ivory background, jade/ink type; terracotta/gold sparingly. Bitter for headings, Atkinson Hyperlegible for explanatory labels, Barlow Condensed ExtraBold for emphatic numbers. If a named font is unavailable, install it locally or use a close fallback and flag the substitution. Verify glyph coverage for arrows and ≠. Use simple vector drawings, and isolated generated object assets when specified. Every card has a visual object, relationship or diagram, not just a paragraph.

Text sizes: key headings about 72–100 px, short secondary labels 44–56 px; adjust for fit. Safe margin at least 100 px. No tiny citation footer, full-screen transcript, big paragraph, fake historical quotation or animated transition. Use direct cuts between card states. A key number can stay while relevant icons change. Hold short names long enough to read, even when the voice says them quickly; do not show them ahead of first mention.

A-ID artwork has NO baked-in words. Names/dates can be a short label over a clean ivory strip or a separate illustrated ivory card; never cover a face or key prop. For repeated names, show the relationship/action when it matters, rather than flashing a bare name again. Eg “Hosted by Yun Si-dong’s wife,” not an image identifying the wife as Yun Si-dong.

Exact name spellings: Kim Man-deok; Jeju; Joseon; King Jeongjo; Hanyang; Yun Si-dong; Lady Hyegyeong; Chae Je-gong; Mandeokjeon; Mount Geumgang; Kim Jeong-hui; Asia’s Past. Years on screen use digits, although spoken years use words. No name from phonetic TTS/ASR is substituted. Source citations remain in description.
